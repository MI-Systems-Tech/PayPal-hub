# PayPal Hub: frontend

Website for PayPal Hub: find what you need, pay with PayPal, and keep subscriptions in check with the Guardian.

Stack: React, Vite, Three.js. Deploy: Vercel (root directory `frontend`).
Env: copy `.env.example`; `VITE_API_URL` is the backend address.
Status: home page in progress. Card art is a sample, not a real payment card.
